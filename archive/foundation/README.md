# Peau Foundation — archivée

Foundation a été la peau par défaut de Forma jusqu'à la `v0.5.0`. Depuis la `v1.0.0`, Forma est le design system du lab (ex-peau Lab) et Foundation n'est plus dans le paquet (décision D9, PRD v1.3).

- `forma.tokens.json`, `forma.css` : copies exactes de la `v0.5.0`.
- `index.html` : galerie vivante d'origine, rendue par la copie locale de `forma.css`.

Une app qui utilise Foundation reste épinglée sur `npm i github:fsapro/design-system#v0.5.0` (ou `#v0.4.0`) et migre vers `v1.0.0` au cas par cas. Ces fichiers ne sont plus maintenus.
